### 4. Show HN: Semble – Code search for agents that uses 98% fewer tokens than grep

- **Points**: 181
- **Comments**: 45
- **URL**: https://github.com/MinishLab/semble
- **HN**: https://news.ycombinator.com/item?id=48165012

**Summary**
Semble offers semantic code search positioned for agents with dramatically lower token use than grep — but HN wants end-to-end agent benchmarks, not grep-replacement micro-benchmarks.

**Key discussion**

- On small codebases, dumping the whole repo into context via startup hooks can beat blind search — related projects give models outlines with stubs.
- Models are RL'd on grep and don't trust LSP/alternative tools — retry loops erase token savings.
- Author ran informal pi + GPT-5.5 evals: **both tools off** beat RTK or Semble on total conversation cost because turn count rose despite lower per-turn context.

**Why it matters**
Named example of the **wrong metric** problem in agent tooling — token savings ≠ task completion cost. Read with X's Evaluation Trap and cognition→action papers.
